# 🪐 3D Orbit Delivery Hero

An interactive, responsive 3D hero component built with **React**, **Three.js**, **React Three Fiber (R3F)**, **Vite**, and **Tailwind CSS**.

## ✨ Features

- 🌍 **Interactive 3D Planet**: Drag to rotate, velocity-based momentum, and smooth physics.
- 🏃 **Animated 3D Courier**: Skinned mesh runner character with dynamic stride, lean, and greeting wave animations.
- 🎨 **Theme Aware**: Supports light & dark modes with automatic color adjustments.
- ⚡ **Optimized Performance**: Preloaded GLTF/GLB models with DRACO compression and efficient rigid bag parenting.
- 🚀 **Vercel Ready**: Preconfigured with `vercel.json`, SPA routing rewrites, and asset caching headers.

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **3D Graphics**: [Three.js](https://threejs.org/) & [@react-three/fiber](https://r3f.docs.pmnd.rs/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/divyanshu-builds-ui/3D-orbit-delivery.git

# Navigate into the project
cd 3D-orbit-delivery

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173` to explore the interactive 3D world.

### Build for Production

```bash
npm run build
```

The production bundle will be generated in the `dist/` directory.
